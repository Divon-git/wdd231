WDD 231 Course Homepage starter

1. Open this folder in VS Code.
2. Add your own optimized student photo as images/profile.jpg (keep it under 125 kB).
3. Replace YOUR-GITHUB-USERNAME and YOUR-LINKEDIN-USERNAME in index.html.
4. Check the course list in scripts/courses.js against the official courses.js linked in your assignment.
5. Change completed: true only for courses you have completed.
6. Replace the Chamber and Final navigation href values when those project pages exist.
7. Run the page with Live Server and test at mobile and desktop widths.
8. Run Lighthouse and the WDD 231 homepage audit before submitting.

The supplied course data is a starter list based on the certificate course names. The assignment's official courses.js file is the authority for exact object properties and credit values.
